SECURITY FIRST
اہم: یہ ڈائریکٹری موجودہ ٹولز اور مطلوبہ integrations کی فہرست ہے، کسی connector secret یا API key کا ذخیرہ نہیں۔ API keys صرف Vercel Environment Variables میں server-side رکھی جائیں؛ browser HTML/JavaScript میں کبھی نہیں۔ ہر connector کو کم سے کم مطلوبہ permissions دی جائیں۔
اشاعت کا اصول: کوئی connector، AI director یا workflow خودکار طور پر خبر شائع نہیں کرے گا۔ Fact-check PASS صرف ادارتی سفارش ہے؛ Admin کی واضح منظوری کے بغیر Production publish ممنوع ہے۔
حیثیت کی وضاحت: “ChatGPT Connected” کا مطلب ہے کہ اس گفتگو میں متعلقہ connector tools دستیاب ہیں؛ اس کا مطلب یہ نہیں کہ وہ پہلے ہی ویب سائٹ کے backend سے OAuth/API کے ذریعے جڑ چکے ہیں۔ Vercel project connector check میں اس وقت صفر connectors ملے۔
