# AI Chronicals News — 26-Department Practical Training Matrix

Status: preview-branch training material. These are controlled exercises, not live reporting, agent certification, or publication authorization.

## How to run every exercise

For each department, run the same seven-stage pipeline: (1) independent search/research, (2) Research & Source Analyst, (3) Storyline & News Writer, (4) Fact-check & Evidence Auditor, (5) Graphics & Visuals Designer, (6) Presentation & Distribution Producer, and (7) Department Head Director review.

Use synthetic case packets or clearly labelled historical examples. Never fabricate a source to make an exercise pass. If a real source is required, use an authorized search tool and preserve its title, publisher, date, HTTPS URL and the exact claim it supports. If evidence is unavailable, the correct result is REVISE or HOLD.

For each of the five specialists and the Director, record: test version, input packet, tool selection, output, score /100, PASS/REVISE/HOLD, reviewer notes, correction, rerun result and approval status. PASS requires 90–100; REVISE 75–89; HOLD below 75. Fabricated evidence, privacy breach, secret exposure or approval bypass is automatic HOLD.

## Shared specialist acceptance checks

- Research: claim-to-source map, primary-source preference, dates/units/jurisdiction, contradiction and limitation notes.
- Storyline: evidence-led headline, neutral copy, close attribution, no invented quote or claim, uncertainty preserved.
- Fact-check: atomic claims, source relevance/directness, explicit statuses, material gaps and correct HOLD decisions.
- Graphics: no invented numbers, clear provenance/rights status, accessible layout, truthful captions and alt text; do not claim an asset exists when it does not.
- Presentation: channel variants preserve caveats, SEO remains accurate, links and credits checked, publication status remains draft.

## Director acceptance checks

The Department Head must review all five outputs, verify role handoffs, reconcile contradictions, return structured findings, and never upgrade an unsupported claim. Director PASS is not Admin approval. All packages remain PENDING_ADMIN_APPROVAL and publication DISABLED.

## Rollout and evidence ledger

1. Run one synthetic exercise per department in a controlled staging environment.
2. Capture separate specialist and Director scores; do not award certification from routing tests alone.
3. Correct the failing role prompt or knowledge record and rerun the same case.
4. Run cross-department regression tests after prompt or rubric changes.
5. Record tool connection, persistent memory/RAG implementation, fine-tuning and live deployment as separate evidence-backed milestones.
6. Do not merge to main or deploy Production without explicit Admin authorization.
